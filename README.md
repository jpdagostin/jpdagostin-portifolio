## Sobre

Desenvolvedor Back-End com sólida experiência em projetos de Inteligência Artificial e Engenharia de Dados. Graduado em Engenharia de Software e pós-graduado em Data Science, com trajetória que combina desenvolvimento de sistemas escaláveis, construção de pipelines de dados e integração de soluções inteligentes em produtos reais.
